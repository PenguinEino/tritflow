# ノートブック v2 の骨格（たたき台）

2026-10-20。フロー本体はほぼ完成したので、ノートブックは一から作り直す。まず骨格を決め、0章と最終章から作り、各章をColabで動かして見てもらいながら進める。

## 決まったこと（2026-10-20、著者と相談）

- 主題：三値のHDLが、製造できるGDS（DRC/LVS済み）になる。自分で書き換えられる。語り口は設計ツールの紹介。
- 冒頭の下に、Code-a-Chipの3つの価値（再利用・再現・教育）をそれぞれどう実現し、どの章で体験できるかを示す。あとはColabを進めると実感できる流れにする。
- 「なぜ三値か」の順番：
  1. つかみ：3値は今も使われている（GDDR7とUSB4 v2のPAM3、重みが{−1, 0, +1}のLLM）。
  2. 空白：三値論理の研究は新デバイスやシミュレーション、合成はゲートネットリスト止まり（GT-LOGIC, IEEE Access 2025）。製造できるオープンソースPDKでGDSまで通す道は見当たらない。
  3. TritFlow：TR-1umで、テープアウトした三値セルからHDL→GDS→DRC/LVS→抽出後SPICE。
  4. 場の意義：TR-1umは日本で初めて商用ファブが公開したオープンソースPDK。型破りな回路を実際のテープアウトと組み合わせて実証することは、オープンソース半導体のプロセスの選択肢を増やし、日本のオープンソース半導体の芽吹きになる。冒頭では1文、詳しくは最終章。
  5. 実証と価値：①設計（済み、誰でも再現）②シリコン（2027年1月到着、ISSCCで実測と予測）③再利用（TritFlowの加算器を次のOpenSUSIシャトルに出す予定）。これが、日本の新しいオープンソースPDKが標準外の回路でも設計→製造→実測を一巡できると世界に示す最初の例になる。お願い調にはせず「この実証が何を可能にするか」として書く。
  6. 平衡三値の性質（符号ビット不要など）は算術の章で触れる。
- 教育の価値：デジタルなのに、アナログ的な調整が要る部分が少しあるので、学ぶ題材として悪くない。「なぜ三値か」ではなく教育の段落で書く。
- 図1は著者とやり取りしながら作る。
- 最初の回路は `y = a & ~a`。二値なら常に0だが、三値ではa=0で0が残る。INV×2とNAND×1の3セル。
- 流れは「全体→部品→組立て」。最初に素朴な回路を一気にGDSまで通し、そのあと中を開ける。
- 実行順の誤り：トレースバックではなく、「先に◯◯を実行してください」と見やすく出す。
- 書き方：オープンソースPDKと呼ぶ（「NDA不要公開PDK」は繰り返さない）。
- 最終章に元のMACチップの予測表は作らない。測定計画は文章で書く。

## チップ（2027年1月到着）について

1トリットの乗算加算回路（MAC）が1つ：X + A×B + Cin = Sum + 3×Cout。出力はSum、Cout、AND=min(A,B)、OR=max(A,B)。ANDとORはNAND→INV、NOR→INVの出力なので、ゲートに近いレベルの動作も測れる。入力は81通り。TritFlowのレイアウトは載っていない（元の手描きレイアウト）。

## 横断する決まり

- 実行できるセルは、処理の前に時刻つきで何をしているかを出す。
- 実行順を誤ったら、トレースバックではなく「先に◯◯を実行してください」と出す。
- 本文の数字は、セルの出力として見せる。生成器と数値の差し込みは使わない。
- 各章のassertと証拠表はノートブックから外し、テスト（ノートブックを実行するpytest）に移す。ノートブックには付録Bの検証セル1つだけを置く。
- 日本語版を確定させてから、英語版を同じセル構成で作る。
