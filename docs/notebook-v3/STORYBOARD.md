# ノートブック v3 の骨格

2026-10-23、著者と相談して決めた方針。v2（`docs/notebook-v2/STORYBOARD.md`）の見た目、書き方、ログ、
操作の部品はすべて引き継ぐ。v2 の「横断する決まり」はそのまま有効。変えるのは題材と章の役割だけ。

## v2 から変える理由

採択作品（ISSCC26・VLSI26 など9本）を読み比べた結果、どれも「手法の各段のすぐ後にその結果」を
一直線に置き、最後に適用と定量的な結果をまとめていた。v2 は1章の `a & ~a` で1周、3〜5章の
2トリット加算器でもう1周しており、2周目が「別のおもちゃのデモ」に見えた。また冒頭の BitNet を
本編で回収していなかった。

## 決めたこと

- dot4 は `assign y = w0*x0 + w1*x1 + w2*x2 + w3*x3;`（46セル、全6561入力で等価）。和は全加算器1個と
  半加算器2個。テープアウトしたチップ（`~/balanced-ternary-logic`）は1トリットの積和
  X + A×B + Cin = Sum + 3·Cout で、dot4 はその4項版にあたる。
- 3章では dot4 の回路図を出さない。46セルの平らな回路図は読めず、全入力の前計算で HTML が 4.4 MB になる。
  部品の MUL と全加算器を値のボタン付きで見せ、全体の形は4章の配置配線で見せる。
- 5章の SPICE は重み w = (+1, −1, +1, +1) を固定し、x だけを変える（推論と同じ使い方）。
  値の変わらない入力は波形のレーンを省き、条件の行に固定値を書く（`notebook/views.py`）。
- 手元の実測（aarch64 VM）：dot4 の配置配線 2.4 s、DRC 0、LVS 一致、SPICE 31 s、STA と SPICE の差 −10%（y[1]）、
  −3%（y[0]）。add2 の比から Colab の SPICE は約 4 分と見込む。
- 入力がすべて 0 の区間で VDD の電流は約 16 mA（±5 V で約 160 mW）。6章で静的電力を数字で扱う。
