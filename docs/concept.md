## 主題

**OpenSUSI TR-1umで、三値論理のHDLからGDSまでを通すパイプライン。**
読者は三値論理を理解しながら、その動作を追っていく。

- 想定読者：二値のCMOS・合成・P&R・SPICEを知っている設計者（審査員は専門家）
- 方針：見た目は分かりやすく、出てくる成果物は本物（SPICEネットリスト、TR-1umのGDS、DRC/LVS、抽出後のngspice）
- 採らない切り口：「二値の常識を覆す」。「三値は二値より優れている」とも主張しない。

## 技術的な前提

- PDK：[OpenSUSI/TR-1um](https://github.com/OpenSUSI/TR-1um)。Apache-2.0（東海理化の原本 openIP62 もApache-2.0）。
- 電源：VDD=+5 V、VMID=0 V、VSS=−5 V。範囲内として扱う（2026-10-18決定）。
- 配線層はM1・M2の2層。PDKの二値スタセルは高さ62.6 µm、内部M1のみ。三値スタセルも同じ作法に揃え、M2をセル上の配線に使う。
- 電源レールは3本（VDD・VMID・VSS）。NANYはVMIDを使い、INV・NAND・NORはVDD/VSSのみ。
- フルカスタム用DRCはPDK側で開発中だが、PCellだけで構成するので問題ない。
- 加算器はNANYとINVだけで組める（HA=NANY×5＋INV×2、FA=NANY×11＋INV×5）。
- 元設計：[opensusi-tr10-balanced-ternary-logic](https://github.com/PenguinEino/opensusi-tr10-balanced-ternary-logic)。セルは `layout/build_*.py`（klayout.db＋PCell）で生成されている。

## HDL（2026-10-18決定）

Verilogに近い独自言語。組合せ回路のみ。パーサーはPythonで書く。

- 型：`trit`（Verilogの4値 `x`/`z` とは別物と明記）。`trit [N-1:0]` のベクトル
- 対応：`module`／`input`・`output`・`wire`／`assign`／名前付きポート接続でのインスタンス化／`parameter`／`generate for`
- 演算：`~a`＝符号反転（INV）、`a & b`＝min、`a | b`＝max、`nany(a, b)`＝−sat(a+b)
- 定数：`4'tT01T`（Tが−1）
- ゲートプリミティブ：`nany g1 (t, a, b);`、`inv g2 (na, a);`。合成結果もこの形で同じ言語として見せる
- 非対応（初版）：`always`・`reg`・順序回路、`+`・`*` などの算術演算子、`x`・`z`

## スタンダードセル（2026-10-18決定）

### セルの種類

| 分類 | セル | 機能 | 中身 |
|---|---|---|---|
| 論理 | `INV` | −a | MOS 2個＋抵抗2本 |
| | `NAND` | −min(a, b) | MOS 4個＋抵抗2本 |
| | `NOR` | −max(a, b) | MOS 4個＋抵抗2本 |
| | `NANY` | −sat(a+b) | MOS 8個＋抵抗2本。VMIDを使う唯一のセル |
| 定数 | `TIEP` / `TIEZ` / `TIEN` | +1 / 0 / −1 | レールを出力ピンへ引き出す |
| 物理 | `FILL` | なし | 隙間を埋め、レールとウェルをつなぐ |
| 任意 | `BUF` | a | INV×2。ファンアウトの多い信号用（後回し可） |

- 駆動力はX1のみ。
- INVの寸法はMAC改善版（2026-09-24）でHA/FAに使った寸法に揃える：`inverter` のMOS W/L、抵抗はW=2.8 µm・L=30 µm。
- PTI/NTI（2MOSの試作）はライブラリに入れず、1〜2章の教材として使う。

### 電源レール

上から **VDD ／ セル本体 ／ VMID・VSS**（案A）。

- VMIDをセルの中央に通すと、PMOSとNMOSをつなぐ出力のM1を横切るため不採用。
- INV・NAND・NORにとってVMIDレールは通過するだけで、隣のNANYへVMIDを届ける役目を持つ。
- NANYは、クランプPMOS（上側）から下側のVMIDまで、セル内でM1を縦に通す。

### 作法

1. 高さは全セル共通、幅は配線格子の整数倍。
2. 内部はM1とポリを基本とする。セルを小さく保つためならM2・V1も使ってよいが、すべて障害物として抽象情報に載せる（2026-10-18変更：M2禁止では初版の高さが462 µm、面積が元セルの18〜26倍になったため）。面積は元のセルの約2倍以内を目標にする。
3. ピンはM1で、配線格子の縦線上に置き、上からV1で降りられる大きさを確保する。
4. ウェルと基板コンタクトはセルごとに内蔵し、並べるだけで連続させる（タップセル不要）。
5. セル枠（prBoundary 235/0）を描き、突き当てでDRCが通るよう両端に間隔の半分ずつを確保する。
6. 向きはR0と左右反転のみ。上下反転はレール順が変わるので禁止。
7. 全セルをPythonスクリプトでPCellから生成し、DRC/LVSまで自動で回す。
8. 各セルに、GDS、回路図由来SPICE、抽出SPICE、端子情報（LEF相当のJSON）、特性表、真理値表を揃える。

参考：PDKの二値スタセル（`STDLIB/LogicCells`）は高さ62.6 µm、上下のM1レールに基板・ウェルコンタクトを内蔵し、ピンは内部のM1で、M2は不使用。

## 合成（2026-10-18決定）

1. パース → `parameter`・`generate` の展開 → 階層を平らにした演算グラフ（演算は neg・min・max・nany・定数）。
2. 書き換え：定数伝播、二重反転の除去、共通部分の共有、未使用回路の削除。三値で成り立つ規則だけを使う。
3. セル割当：`~a`→INV、`~(a&b)`→NAND、`a&b`→NAND＋INV、`~(a|b)`→NOR、`a|b`→NOR＋INV、`nany`→NANY、定数→TIE。
4. ファンアウト上限（既定4、特性評価で見直す）を超えたらBUFを挿入。
5. 等価性の確認：入力12トリット以下は全入力（3^12≈53万通り）、それ以上は乱数10万通り。書き換え前後と、ゲートレベル結果を照合。
6. 出力：ゲートプリミティブ形式のTritVerilog、SPICEネットリスト。`module` の階層はサブ回路名として記録する。

## 配置配線（2026-10-18決定）

| 段階 | 方式 |
|---|---|
| フロアプラン | セル行と配線チャネルを交互に置く（2層配線で最も確実な形） |
| 電源 | 各行のレールを両端の縦の幹線（M2）に束ねる。レール幅は行の静的電流から決める |
| 配置 | 信号の流れ順に並べた初期配置を、焼きなまし法で入れ替えて配線長（HPWL）を縮める。過程は記録してアニメーションにする |
| 配線 | 格子上の迷路配線（A*）。M2は縦（セル上も可）、M1は横でチャネル内のみ。失敗したら引き剥がし再配線、それでも駄目ならチャネルを広げる |
| 入出力 | 外周にM2のピンとラベル |
| 出力 | 階層付きGDS（セル参照＋配線セル）、配置配線情報（DEF相当のJSON） |
| 検査 | DRC、LVS、配線長・配線容量の一覧、電源の電圧降下 |

三値特有の論点：INV・NAND・NORは0 VをVDD/VSSの抵抗分圧で作るため、電源の電圧降下は0の出力レベルを直接ずらす。レールを抵抗網として解き、セル位置ごとの電源電圧と0レベルのずれを報告する（7章の結果の一つ）。

## 抽出とSPICE（2026-10-18決定）

- 抽出：PDKのKLayout LVSデッキで素子と接続を抽出。配線容量は形状（面積＋周囲長×層ごとの係数）から自前で見積もり、ネットごとの集中容量として付ける。サインオフ品質のPEXではないと明記する。
- 配線抵抗：信号は無視、電源は電圧降下の解析で扱う。
- シミュレーション：ngspice＋PDKモデル。
  - 判定：各区間の終わりに出力が理想値±0.5 Vに入っているか。
  - 遅延：入力変化から、出力が目標値の±0.5 V帯に入って留まるまでの時間（整定時間）。二値の50%閾値の代わり。
  - 静的電流：入力組ごとに測る。
  - 比較：配線前（合成ネットリスト）と配線後（抽出ネットリスト）、負荷の掃引。
- 全入力の過渡試験は入力の少ない回路（〜6トリット程度）まで。大きい回路は代表パターンと最悪経路。

## 特性評価（2026-10-18決定）

各セルについて、DC出力レベルの誤差、入力組ごとの静的電流、入力容量、負荷（10 fF・100 fF・1 pF）ごとの整定時間を測り、表にする。2・3章の教材と、合成のファンアウト上限に使う。
