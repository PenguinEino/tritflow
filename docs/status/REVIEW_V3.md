Ranked by impact on acceptance:

1. **Correct the BitNet scope (opening; §3.7).** “The matrix products in BitNet b1.58 … consist of repeated dot products of ternary weights … and inputs” makes dot4 sound representative of that workload. BitNet b1.58 uses **8-bit activations**, while every x here is one trit ([original paper, §2][bitnet]). Write: “Motivated by ternary-weight models, we demonstrate a four-term dot product with one-trit weights and activations.” State that activation precision, accumulation, scaling and memory for BitNet inference are future work. Present area/power as properties of this demonstrator; no neural-network efficiency conclusion follows.

2. **Qualify the exact release artifact (setup; 5-3).** The source pins `768124f`; the reviewed execution pins `d7ee0dc`. Normalized cell sources differ only in that pin and asset URLs, but this run uses **KLayout 0.30.9**, whereas setup pins **0.30.6**. It passes 25/25 cells in 62.5 s with ngspice-42; its 0.3 s setup measures an already provisioned local run. A parallel `tritflow_en_output.ipynb` appeared late with the current pin, Colab paths and matching pinned versions, but cleared execution counts and no execution timestamps. Attach its cold Run-all completion/timing and widget qualification record. Ship saved release outputs: the source notebook has none. Add author/affiliation, an Open-in-Colab link and short runtime/Run-all instructions. Current asset and Plotly-CDN URLs respond successfully; retain static previews because GitHub will not execute widget JavaScript. Ordinary-browser GDS displays “Static overview · rerun in Colab for live detail”; explain that dependency.

3. **Separate the verification guarantees (§§3.6, 5.3–5.4).** “All 6561 input vectors equivalent” checks digital synthesis. Analog dot4 simulation exercises **11 intervals with one fixed weight vector**, not all input combinations or transitions. State both coverage counts beside the results. The STA comparison is **133.5/120.7 ns** for y[1] and **227.4/219.9 ns** for y[0] (SPICE/STA): it underestimates both. Add one sentence explaining the visible glitches and the limits of vector-conditioned STA; these two output maxima establish neither a conservative bound nor general timing accuracy. Preserve §5.2’s unusually clear disclosure that wire-C coefficients are uncalibrated and omit coupling/resistance.

4. **Bound novelty and silicon claims (opening).** “No design flow … has been reported” has no supporting related-work references. Cite the closest ternary synthesis flows, the original cell repository, and primary TR-1um/shuttle documentation; identify the contribution as their integration into this executable open-PDK flow. “Suitable for tapeout” needs the distinction between core DRC/LVS and completed shuttle preparation. State explicitly: underlying circuits were submitted for fabrication; these generated standard-cell layouts and dot4 have no silicon measurements yet. Replace the promised ISSCC measurements with a plan conditional on chip delivery and successful testing. Repair the opening’s references to absent chapters 6 and 7 when the final structure is known.

5. **Turn analog explanations into a design decision (§2.1; chapter 6).** The divider equations and sizing plot are good, but never plug a resistance into the equations and compare the prediction with −40 mV/407 µA. Add that small worked comparison and explain the residual. Define “RR” on first use and substantiate “at least 20” with its bias/dimensions. One zero-output INV already dissipates approximately **4.07 mW across the 10 V rail span**. Report this cost explicitly. The ±0.5 V nominal acceptance band establishes neither PVT robustness nor measured noise margins; describe the −1 to +1 V input test as a nominal tolerance check.

6. **Make the interactive teaching purposeful (§§2–5).** “Allowing newcomers to logic design” overstates the assumed CMOS/HDL/EDA knowledge. Name the actual audience and add a prediction/change/observation prompt: change INV resistor length and predict current; set a=+1, b=−1, op=0 to expose the selector difference. In §3.1, explain that condition “unknown” is a defined physical 0 trit, distinct from Verilog X/Z. In **3-6**, the 32-cell selector drawing is too small to trace at notebook width; group its MUX3 structure and expand details on demand. In **2-4**, mark A/B/Y access points on one enlarged cell. Move the unmotivated annealing percentages into optional details. Replace “The resulting GDS is shown below” and repeated chapter-ending summaries with what the reader should inspect. Explain why the fanout limit is four.

7. **English edits (lower impact).** The prose is generally readable; these phrases need tightening:

   | §2.1: “The RR resistance” | “The resistance of each diffusion resistor (PDK device RR)” |
   | §2.4: “Place and route abuts cells” | “Cells abut in horizontal rows to connect their power rails.” |
