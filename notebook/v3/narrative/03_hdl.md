## 3. HDLと論理合成

2章では、TritFlowのセルライブラリが任意の三値論理を網羅できる機能的完全性を備えていることを確認した。本章では三値回路専用のHDLである「TritVerilog」と、その記述をスタンダードセルの接続網へと変換する論理合成エンジンについて見ていく。TritVerilogは業界標準のVerilog HDLの構文体系を三値へと自然に拡張したものであり、直感的な文法で三値デジタル回路を設計できる。

### 3.1 値と数

信号の値（トリット）は−1・0・+1で、電圧の−5 V・0 V・+5 Vに対応する。条件として使うときは、偽・不定・真を表す。不定は物理的な0 Vに対応する有効なトリット0であり、Verilogの未定義値Xや高インピーダンスZとは異なる。

複数のトリットを束ねたベクトル（例：`trit [1:0] a;`）は、**平衡三値**（Balanced Ternary）による整数値を表す。下位から数えて第 i 桁の重みは 3<sup>i</sup> となる。数値リテラルでは値 −1 を記号 `T`（あるいは小文字 `t`）で表記する。たとえば `2'tT1` は−1·3 + 1 = −2 を表す。一般に n トリットでは −(3<sup>n</sup> − 1)/2 から +(3<sup>n</sup> − 1)/2 までの 3<sup>n</sup> 通りの整数を過不足なく表せ、2トリットなら −4 から +4 までの9通りになる。

平衡三値記数法には、二進数表現（2の補数表現など）にはない優れた特徴がある。

- **符号ビットが不要**：−1 を対称に含むため、特別な符号ビットを設けることなく、正数・ゼロ・負数を単一の形式で対称に表現できる。
- **符号反転が瞬時に完了**：数全体の符号を反転（−a）させるには、単にすべての桁の正負を反転（T ↔ 1）するだけで済む。2の補数表現のように「全ビットを反転した上で最下位ビットに1を加算する」というキャリー伝搬の遅延が一切生じない。
- **切り捨てが最も近い値への丸めになる**：各桁が −1・0・+1 なので、下位の桁を捨てたときの誤差は、捨てた桁の重みの半分以内に正負対称に収まる。TritVerilogの `a >> 1`（3で割って最も近い整数に丸める）も、最下位の桁を捨てるだけでこの丸めになる。

### 3.3 論理合成の流れ

論理合成は次の段で進む。

1. 展開：HDLを構文解析し、モジュールの階層、パラメータ、`generate` を展開して、式の中間表現にする。`always @*` の中の手続きは代入のたびに各信号の現在値を更新する形（静的単一代入）に直し、`if` と `case` の分岐は値の選択に変える。
2. 写像：演算ごとに決まった構造に置き換える。加減算はテープアウトした回路と同じ構造の半加算器と全加算器を桁上げでつないだ回路に、比較は各桁の差を飽和させて上位桁から符号を決める回路に、等号と `case` のラベルは桁ごとの一致検出器に置き換える。選択は次の3.5で述べる。
3. 最適化：定数の畳み込み、共通部分式の共有、使われない論理の削除、三値で成り立つ恒等式（−(−x) = x、min(x, x) = x、min(x, +1) = x、max(x, +1) = +1、NANY(x, 0) = −x、min(−a, −b) = −max(a, b) など）による簡単化を行う。
4. 接続数の制限：SPICEのシミュレーションで、1つの出力に同じセルを8個つないでも正しいレベルが出ることを確かめた。これに余裕を持たせ、1つのセルの出力につなぐ入力を既定で4本までとし、超える分はBUFを木の形に重ねて分ける。
5. 等価性の検証：合成した回路網がHDLと同じ関数であることを確かめる。

### 3.4 算術：`+` と `*`

1トリットどうしの和は−2から+2の範囲になるため、桁上げが要る。たとえば 1 + 1 = 2 = 3·1 + (−1) で、和の桁は−1、桁上げは+1になる。全加算器は a + b + c<sub>in</sub> = s + 3c<sub>out</sub> を満たす回路である。TritFlowの論理合成はHDLの `+` を、テープアウトした回路と同じ構造の全加算器（NANY 11個とINV 5個）に展開し、多桁ではそれを桁上げでつなぐ。

### 3.5 選択：場合分けを回路にする

`if`・`case`・`?:` で書いた場合分けは、条件に応じて候補のどれか1つを出力に通す回路（選択回路）に置き換える。二値では条件が0か1なので、選択回路はANDとORで作れる。三値では条件そのものが−1・0・+1をとりうるため、条件が0のときの出力も決めておく必要がある。論理合成は、条件が0をとりうるかどうかで、2種類の選択回路を使い分ける。

例として、1トリットの入力 a、b、op から、op が +1 なら a を、−1 なら b を出力 r に出す回路を2通りに書く。

<!-- code: sel_source -->

1つ目は比較 `op == 1't1` を条件にしている。この比較の結果を s とすると、s は真（+1）か偽（−1）のどちらかで、0にはならない。op = 0 のときは偽なので b を選ぶ。条件が0にならなければ、出力 r は二値のANDとORによる選択と同じ形の次の式で作れる。

$$r = \max\bigl(\min(s,\ a),\ \min(-s,\ b)\bigr)$$

s = +1 なら min(s, a) は a、min(−s, b) は −1 になり、max をとると a が残る。s = −1 なら、同じように b が残る。min、max、符号反転は、NAND、NOR、INVで作れる。`case` も、ラベルとの一致を条件にすれば同じ形になる。

2つ目は op をそのまま条件にしているので、op = 0 の場合が残る。TritVerilogでは、このとき a と b が一致すればその値を、一致しなければ0を出すと定めている。多トリットの値では桁ごとに比べる。この振る舞いには条件の3つの値それぞれに対応する入力を持つ三値の選択回路（MUX3）を使う。

2つ目はMUX3が要るため、1つ目より大きくなる。論理合成は、条件が0をとらないことを中間表現の上で確かめてから、1つ目の形を使う。

### 3.6 等価性の検証

論理合成は、合成した回路網がHDLと同じ関数になっていることを、合成のたびに確かめる。HDLの意味は整数と真理値表の規則で、回路網はセルの真理値表で、それぞれ別々に計算し、出力を比べる。入力が12トリット以下なら全組合せを、それより多ければ乱数で選んだ10万通りを比べる。ここまでの合成結果の「全○入力で一致」は、この検証の結果である。

### 3.7 三値重みの積和
