## 1. 最初の回路：`a & ~a` をGDSにする

二値の論理では、`a & ~a` はaが何であっても偽になる。三値ではそうならない。

| a | `~a` | `a & ~a` |
|---|---|---|
| −1 | +1 | −1 |
| 0 | 0 | **0** |
| +1 | −1 | −1 |

| `a & b` | b = −1 | b = 0 | b = +1 |
|---|---|---|---|
| a = −1 | −1 | −1 | −1 |
| a = 0 | −1 | 0 | 0 |
| a = +1 | −1 | 0 | +1 |
