## 3. HDLと論理合成

2章では、TritFlowのセルの組で任意の三値論理を作れることを確かめた。本章では、回路を書くHDLであるTritVerilogと、それをセルの回路網に置き換える論理合成を見る。TritVerilogはVerilogの組合せ回路の書き方を三値に広げたものである。書き方を順に紹介し、それぞれが何に合成されるかを示す。

### 3.1 値と数

信号の値（トリット）は−1・0・+1で、電圧の−5 V・0 V・+5 Vに対応する。条件として使うときは、偽・不定・真を表す。`trit [1:0] a` のようなベクトルは平衡三値の整数を表し、桁 $i$ の重みは $3^i$ である。リテラルでは−1をTと書き、たとえば `2'tT1` は −1·3 + 1 = −2 を表す。2トリットで−4から+4を表せ、符号ビットは要らない。符号反転は、すべての桁を反転するだけで済む。

### 3.3 論理合成の流れ

論理合成は次の段で進む。

1. 展開：HDLを構文解析し、モジュールの階層、パラメータ、`generate` を展開して、式の中間表現にする。`always @*` の中の手続きは、代入のたびに各信号の現在値を更新する形（静的単一代入）に直し、`if` と `case` の分岐は値の選択に変える。
2. 写像：演算ごとに決まった構造に置き換える。加減算は、テープアウトした回路で検証された半加算器と全加算器を桁上げでつないだ回路に、比較は各桁の差を飽和させて上位桁から符号を決める回路に、等号と `case` のラベルは桁ごとの一致検出器に置き換える。選択は次の3.5で述べる。
3. 最適化：定数の畳み込み、共通部分式の共有、使われない論理の削除、三値で成り立つ恒等式による簡単化を行う。二値の補元律（$x \wedge \bar{x} = 0$ など）は、0（不定）では成り立たないので使わない。1章の `a & ~a` が INV 2個と NAND 1個のまま残るのはこのためである。合成した回路網は最小であることを保証しない。
4. 接続数の制限：1つのセルの出力につなぐ入力を4本までとし、超える分はBUFを木の形に重ねて分ける。
5. 等価性の検証：合成した回路網がHDLと同じ関数であることを確かめる（3.6）。

### 3.4 算術：`+` から全加算器へ

1トリットどうしの和は−2から+2の範囲になるため、桁上げが要る。たとえば 1 + 1 = 2 = 3·1 + (−1) で、和の桁は−1、桁上げは+1になる。全加算器は $a + b + c_{in} = s + 3\,c_{out}$ を満たす回路である。TritFlowの論理合成は、HDLの `+` を、テープアウトした回路で検証された全加算器の構造（NANY 11個とINV 5個）に展開し、多桁ではそれを桁上げでつなぐ。

### 3.5 選択：場合分けを回路にする

`if`・`case`・`?:` で書いた場合分けは、条件に応じて候補の値のどれか1つを出力に通す回路（選択回路）に置き換える。二値では条件が0か1なので、選択回路はANDとORで作れる。三値では条件そのものが−1・0・+1をとるため、条件が0（不定）のときにどうするかを決めておく必要がある。論理合成は、条件が0をとりうるかどうかで、2種類の選択回路を使い分ける。

条件が必ず+1か−1になる場合。比較（`a < b` など）や、`case` のラベルとの一致（`op == 1't1` など）の結果は、真（+1）か偽（−1）のどちらかで、0にはならない。このときは、各候補 $x_i$ と、それを選ぶ条件 $s_i$（選ぶ候補だけ+1、ほかは−1）から、次の式で出力を作る。

$$r = \max_i \min(s_i, x_i)$$

$s_i = -1$ の候補は $\min$ をとると−1になり、$\max$ の中でほかの値に負けるので、$s_i = +1$ の候補 $x_i$ だけが出力に残る。二値のANDとORによる選択と同じ形で、minとmaxはNANDやNORとINVで作れる。論理合成は、条件が0をとらないことを中間表現の上で確かめてから、この形を使う。

条件が0をとりうる場合。たとえば `op ? x : y` で op をそのまま条件にすると、op = 0 の場合が残る。TritVerilogでは、このとき x と y を桁ごとに比べ、一致する桁はその値を、一致しない桁は決められないので0を出すと定めている。この振る舞いには条件の3つの値それぞれに対応する入力を持つ三値の選択回路（MUX3）を使い、上の形より大きな回路になる。

`case` で書いた真理値表も、ラベルとの一致と上の選択で、どのような関数でも合成できる。

例として、1トリットの a と b から、op が +1 なら a を、−1 なら b を選ぶ回路を2通りに書く。1つ目は比較 `op == 1't1` を条件にしたもので、op = 0 でも b を選ぶ。2つ目は op をそのまま条件にしたもので、op = 0 のときは a と b が一致すればその値を、一致しなければ0を出す。

### 3.6 等価性の検証

論理合成は、合成した回路網がHDLと同じ関数になっていることを、合成のたびに確かめる。HDLの意味は整数と真理値表の規則で、回路網はセルの真理値表で、それぞれ別々に計算し、出力を比べる。入力が12トリット以下なら全組合せを、それより多ければ乱数で選んだ10万通りを比べる。ここまでの合成結果の「全○入力で一致」は、この検証の結果である。
