## 3. HDLと論理合成

2章では、TritFlowのセルの組で任意の三値論理を作れることを確かめた。本章では、回路を書くHDLであるTritVerilogと、それをセルの回路網に置き換える論理合成を見る。TritVerilogはVerilogの組合せ回路の書き方を三値に広げたものである。書き方を順に紹介し、それぞれが何に合成されるかを示す。

### 3.1 値と数

信号の値（トリット）は−1・0・+1で、電圧の−5 V・0 V・+5 Vに対応する。条件として使うときは、偽・不定・真を表す。`trit [1:0] a` のようなベクトルは平衡三値の整数を表し、桁 $i$ の重みは $3^i$ である。リテラルでは−1をTと書き、たとえば `2'tT1` は −1·3 + 1 = −2 を表す。2トリットで−4から+4を表せ、符号ビットは要らない。符号反転は、すべての桁を反転するだけで済む。

### 3.3 論理合成の流れ

論理合成は次の段で進む。

1. 展開：HDLを構文解析し、モジュールの階層、パラメータ、`generate` を展開して、式の中間表現にする。`always @*` の中の手続きは、代入のたびに各信号の現在値を更新する形（静的単一代入）に直し、`if` と `case` の分岐は値の選択に変える。
2. 写像：演算ごとに決まった構造に置き換える。加減算は、テープアウトした回路で検証された半加算器と全加算器を桁上げでつないだ回路に、比較は各桁の差を飽和させて上位桁から符号を決める回路に、等号と `case` のラベルは桁ごとの一致検出器に置き換える。選択は次の3.5で述べる。
3. 最適化：定数の畳み込み、共通部分式の共有、使われない論理の削除、三値で成り立つ恒等式による簡単化を行う。二値の補元律（$x \wedge \bar{x} = 0$ など）は、0（不定）では成り立たないので使わない。1章の `a & ~a` が INV 2個と NAND 1個のまま残るのはこのためである。
4. ファンアウトの制限：1つの出力がつなぐ入力を4本までとし、超える分はBUFの木で分ける。
5. 等価性の検証：合成した回路網がHDLと同じ関数であることを確かめる（3.7）。

### 3.4 算術：`+` から全加算器へ

1トリットどうしの和は−2から+2の範囲になるため、桁上げが要る。たとえば 1 + 1 = 2 = 3·1 + (−1) で、和の桁は−1、桁上げは+1になる。全加算器は $a + b + c_{in} = s + 3\,c_{out}$ を満たす回路である。TritFlowの論理合成は、HDLの `+` を、テープアウトした回路で検証された全加算器の構造（NANY 11個とINV 5個）に展開し、多桁ではそれを桁上げでつなぐ。

### 3.5 選択：場合分けを回路にする

`if`・`case`・`?:` の場合分けは選択回路に写像する。三値では、選ぶ条件が0（不定）をとりうるかどうかで、必要な回路が大きく変わる。

- 条件が0をとりうる場合：三値の選択回路（MUX3）を使う。任意の関数は1つの入力 $x$ について $f = \mathrm{MUX3}(x;\ f|_{x=-1},\ f|_{x=0},\ f|_{x=+1})$ と展開でき（三値のシャノン展開）、各場合の関数を共有しながら再帰的に組み立てる。`c ? x : y` は、$c = 0$（不定）のとき、$x$ と $y$ が一致する桁はどちらを選んでも同じなのでその値を、異なる桁は決められないので0を出す。この中間の場合は $\mathrm{median}(x, y, 0)$ として実装する。
- 条件が必ず ±1 になる場合：比較や `case` のラベルの一致検出器のように、真（+1）か偽（−1）にしかならない条件は、中間表現の上でそのことを証明したうえで、ANDとORの組で選ぶ。$r = \max_i \min(s_i, x_i)$（$s_i$ はただ1つが+1で残りが−1）で、MINとMAXはNANDとNORにINVを組み合わせて作る。MUX3より小さい回路で済む。

同じ「opが+1なら加算、−1なら減算、0ならaをそのまま」を3通りに書き、合成結果を比べる。3つ目はopとbの積で加算と減算を切り替える書き方で、三値ならではの選び方である。4つ目はopをそのまま条件に使ったもので、op = 0 のときの意味が異なる（a+bとa−bが一致する桁だけを残す）。

`?:` と `case` は、条件が比較や一致検出で必ず ±1 になるため、どちらもANDとORによる選択になり、ほぼ同じ大きさになる。`a + op*b` では、op·b が桁ごとの1トリット乗算（NAND 2個、NOR 1個、INV 1個）になり、加算器を1つ共有するだけで選択回路そのものが要らない。opをそのまま条件にすると、op = 0 を扱う三値の選択回路が要り、最も大きくなる。

### 3.6 任意の真理値表

`case` で書いた真理値表は、入力の組合せごとの一致検出器と、上の ±1 の選択で、どのような関数でも合成できる。1入力の関数は、2.2の手順でINV・NAND・NOR・NANYと3つの定数から27通りすべての実装を前もって求めておき、必要なものを使う。いずれも最小の回路を保証するものではない。

### 3.7 等価性の検証

論理合成は、合成した回路網がHDLと同じ関数になっていることを、合成のたびに確かめる。HDLの意味は整数と真理値表の規則で、回路網はセルの真理値表で、それぞれ別々に計算し、出力を比べる。入力が12トリット以下なら全組合せを、それより多ければ乱数で選んだ10万通りを比べる。ここまでの合成結果の「全○入力で一致」は、この検証の結果である。
