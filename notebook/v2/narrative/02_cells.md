## 2. セル

1章の回路は、INVとNANDの2種類のセルでできていた。本章では、TritFlowの土台であるセルを見る。まず最も基本的なINVで、CMOSで3つの電圧レベルをどう作るかを確かめ、次に、セルの組でなぜ任意の三値論理を作れるのか、テープアウトした回路をどのように配置配線できるスタンダードセルにしたのかを見る。

### 2.1 INV：3つのレベルを作る

二値のINVとの違いは、0 Vを出すために上下のMOSを同時にオンにし、分圧で中間のレベルを作る点にある。

TritFlowのINVは、VDDとVSSの間にPMOS、抵抗、抵抗、NMOSを直列につないだ回路で、出力Yは2本の抵抗の間からとる。

<!-- tables: inv -->

入力が±5 Vのときは片方のMOSだけがオンになり、Yはそちら側のレールにプルアップまたはプルダウンされる。入力が0 Vでは両方のMOSがオンになる。オンのMOSをオン抵抗 $r_{on} \propto (W/L)^{-1}$ で近似し、上側を $R_u = r_{on,P} + R_{RP}$、下側を $R_d = r_{on,N} + R_{RN}$ とすると、

$$V_Y = V_{SS} + (V_{DD}-V_{SS})\frac{R_d}{R_u+R_d},\qquad I = \frac{V_{DD}-V_{SS}}{R_u+R_d}$$

となる。0 Vはどのレールからも供給されず、$R_u = R_d$ の釣り合いだけで作られ、その間は静的電流 $I$ が流れ続ける。RRはオン抵抗の20倍以上あるため、0のレベルはMOSのばらつきよりも、同じ形状の2本の抵抗の比によって支配的に決まる。


#### SPICEでのシミュレーション

テープアウトした寸法を含む90通りの寸法について、ngspiceとPDKのモデルでDC解析した結果を示す。

寸法は、中間レベルの精度、遅延、面積、静的電流のトレードオフで決めた。MOSのゲート長は駆動能力と面積から最小の1 µm、RRの幅は最小の2.8 µmとした。入力0 Vでの出力は $R_u = R_d$、すなわち $r_{on,P} + R_{RP} = r_{on,N} + R_{RN}$ のとき0 Vになる。正孔の移動度は電子より低いため、PMOSの幅をNMOSより広くとって両者のオン抵抗をそろえ、出力オフセットを打ち消した。中間レベルの雑音余裕として、入力 −1〜+1 Vで出力が ±0.5 V以内に収まることを目標とした。RRの長さは、テープアウトしたチップ全体の静的電流を電源配線とビアの許容電流に収めるように30 µmとした。MOSの寸法はRRを延ばす前のまま変えていないため、入力0 Vで数十mVのオフセットが残るが、±0.5 Vの判定帯に対しては十分小さい。

### 2.2 完全性：この組で何でも作れるか

論理合成は、HDLで書いた論理を、用意したセルの組合せに置き換える作業である。どんな論理を書いても置き換えられるには、セルの組が**機能的に完全**である必要がある。機能的に完全とは、その組のセルをつなげば、あらゆる論理関数を作れることをいう。二値では、NANDが1種類あれば完全であることがよく知られている。NOTもANDもORも、NANDをつなげば作れるからである。

三値で同じことを確かめる。まず、入力が1本の論理関数（1入力関数）を考える。入力aは−1・0・+1の3通りで、それぞれに対して出力を3通りから選べるので、1入力関数は 3 × 3 × 3 = 27通りある。たとえばINVは、a = −1, 0, +1 をそれぞれ +1, 0, −1 に移す関数で、27通りのうちの1つである。

あるセルの組で、27通りのうちいくつを作れるかは、次の手順で数えられる。

1. はじめに手元にあるのは、入力aそのものと、定数セルが出す定数だけとする。
2. 手元の関数をセルの入力につなぎ、新しい関数を作る。
3. 作った関数を手元に加えて2に戻る。新しい関数が1つも増えなくなったら終わる。

最後に手元に残った関数が、その組で作れる1入力関数のすべてである。3つのセルの組について数えた結果を示す。

<!-- code: closure -->

結果は、それぞれ次のように説明できる。

- **INV・NAND・NOR＋定数**：NANDとNORは、2つの入力の小さいほう（min）と大きいほう（max）の符号を反転したものである。0を「分からない」と読むと、min・max・符号反転は、分からない入力からは分からない出力しか作らない。このため、a = 0 での出力は、0になるか、aによらない定数になるかのどちらかに限られる。この条件を満たす関数しか作れない。
- **NANY＋TIEZ**：NANYは、2つの入力の和を−1から+1の範囲に切り詰め（sat）、符号を反転したセルで、$\mathrm{NANY}(a, b) = -\mathrm{sat}(a+b)$ である。入力を両方とも符号反転すると、出力も符号反転する。aと0から出発すると、作った関数はどれもこの対称性を持ち続けるので、$f(-a) = -f(a)$ を満たす関数しか作れない。
- **NANY＋TIEP・TIEN**：+1と−1の定数がこの対称性を崩し、27通りすべてに届く。

1入力関数がすべて作れるだけでは、まだ完全とは言えない。Słupecki（1939年）は、1入力関数をすべて作れ、さらに、2つの入力の両方に実際に依存し、出力に−1・0・+1のすべてが現れる2入力関数を1つ作れれば、入力が何本の三値関数でも作れることを示した。NANYはこの条件を満たすので、NANYとTIEP・TIENの組は機能的に完全である。TritFlowの論理合成は、この性質を使って、任意の真理値表をセルに置き換える（3章）。

### 2.3 セルの組

TritFlowのセルの組を以下に示す。INV・NAND・NOR・NANYはテープアウトした回路そのものである。BUFは1つの出力を多くの入力につなぐときの分割に、TIEP・TIEZ・TIENは定数に使う。各セルには、以降の回路図で使う記号を添える。出力の丸は符号反転を表し、NANDとNORは二値と同じ形をとる。NANYは、2つの入力の和をΣで表した記号で、和を−1から+1に切り詰めてから符号を反転する。TIEは、出力する定数を記号の上に書く。

### 2.4 スタンダードセルにする

配置配線では、セルを横一列に並べ、隣どうしを突き当てて電源をつなぐ。そのため、すべてのセルが同じ高さと、同じ位置の電源レールを持つ必要がある。INV・NAND・NOR・NANYは、テープアウトした回路と素子寸法を保ったまま、この共通の枠に入れ直している。VDD・VMID・VSSの3本のレールがセルを横切り、信号ピンはM1の決まった高さに置いて、上を通るM2からビアで届くようにしている。左右反転して置いてもよい。
