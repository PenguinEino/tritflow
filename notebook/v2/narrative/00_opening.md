# TritFlow：OpenSUSI TR-1umで、三値のHDLからGDSへ

3つの値は、実用の場に戻ってきている。GDDR7メモリやUSB4 Version 2.0は3値の信号（PAM3）でデータを送り、重みを−1・0・+1に絞った大規模言語モデル（BitNet b1.58）も登場した。ただし、これらの値を処理しているのは二値の回路である。三値のまま論理を組む研究の多くは、CNTFETやメモリスタのような量産されていない素子か、シミュレーションの上にとどまる。三値のRTL合成も出力はゲートの回路網までで、オープンなツールはCMOS向けには三値を二値に変換する。製造可能なオープンソースPDKの上で、三値のHDLからGDSまでを通す設計フローは、我々の知る限り報告されていない。

本ノートブックでは、これを日本で初めて商用ファブが公開したオープンソースPDK、OpenSUSI TR-1umの上で実現する。著者がテープアウトした三値回路をスタンダードセルにし、三値のHDLから合成、配置配線、PDKのDRC/LVS、ポストレイアウトシミュレーションまでを一つのフローで行う。読者はその場でHDLを書き、自分の三値回路をGDSまで作れる。ライブラリとフローはApache-2.0で公開している。

元の回路を載せたチップは、TR-1umの最初のMPWシャトルで製造され、2027年1月に届く予定である。採択された場合は、2月のISSCCのポスターで、このチップの最初の実測を本ノートブックの予測と並べる。設計、製造、実測を一巡させることで、TritFlowの予測を実測で検証し、オープンソースPDKの上で三値回路の研究を積み上げていける基盤であることを示す。TritFlowで設計した回路も、次のOpenSUSIシャトルに出す予定である。

| Code-a-Chipの価値 | TritFlowでは | 体験できる章 |
|---|---|---|
| 再現 | 「すべてのセルを実行」だけで、同じGDS、検査結果、波形が手元に出る | 1章 |
| 再利用 | 三値のスタンダードセルとフローを公開。HDLを書けば、自分の回路のGDSとシャトル提出用の一式ができる | 7・8章 |
| 教育 | デジタル回路なのに、真ん中のレベルの調整など、アナログ的な考え方が少し要る。手で予想してからSPICEで確かめる | 2・6章 |
