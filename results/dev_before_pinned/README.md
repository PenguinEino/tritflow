# Superseded numerical evidence

The JSON snapshots under results/, build/ and cells/ capture the previous dev-PDK publications before requalification. They are historical, not current qualification.

`earlier_corner_cases/` also contains intermediate pinned-PDK cache generations replaced during the parallel cell/PNR publications. The only current 54 case files are those referenced by `results/corners/summary.json`.

`mul1_unseeded/` retains the nonphysical initial operating-point failure. The current benchmark uses identical soft Newton guesses in both modes.

Current values, consumed hashes and before/after scalar changes are in `results/pinned_requalification.json`.
